# Установка на Windows

Один раз пройти сверху вниз. Занимает примерно час. Пункты 1–3 — программы, 4–6 — ключи,
7 — запуск.

Всё, где написано «выполни», вводится в **PowerShell**: клавиша Win → набрать `powershell` → Enter.

---

## 1. Python

Скачай Python 3.12 с python.org → Downloads → Windows.

При установке **обязательно поставь галочку «Add python.exe to PATH»** на первом экране.
Без неё дальше ничего не заработает, а ошибка будет непонятная.

Проверка:

```powershell
python --version
```

Должно вывести `Python 3.12.x`.

## 2. Git

Скачай с git-scm.com, ставь со всеми настройками по умолчанию.

Проверка:

```powershell
git --version
```

## 3. Claude Code

```powershell
npm install -g @anthropic-ai/claude-code
```

Если `npm` не найден — сначала поставь Node.js LTS с nodejs.org, потом повтори команду.

## 4. Токен бота

1. В Telegram найди **@BotFather**.
2. Отправь `/newbot`.
3. Придумай имя (любое) и username — он должен заканчиваться на `bot`, например `md4_wakeup_bot`.
4. BotFather пришлёт длинную строку вида `8123456789:AAF...`. Это **токен**. Никому его не показывай
   и не выкладывай на GitHub — по нему можно управлять ботом.

## 5. Ключ 2ГИС

1. Зайди на dev.2gis.ru, зарегистрируйся.
2. Запроси **пробный ключ** для сервиса Routing API (маршрутизация).
3. Ключ придёт на почту или появится в личном кабинете.

Если с ключом не сложится — не блокируйся на этом. Скажи Claude Code: «2ГИС не дали, переходим
на OpenRouteService». Регистрация там на openrouteservice.org, бесплатно, но без пробок.

## 6. Файл `.env`

В папке проекта скопируй `.env.example` в `.env` и впиши свои значения:

```powershell
copy .env.example .env
notepad .env
```

Впиши токен из пункта 4 и ключ из пункта 5. Сохрани, закрой.

Файл `.env` попадает в `.gitignore` и на GitHub не уедет — так и должно быть.

**Если Telegram у тебя открывается только через прокси или VPN** (так часто бывает при
доступе из России): впиши тот же адрес в `TELEGRAM_PROXY_URL`. Посмотреть его можно
в Windows: Пуск → «Параметры прокси-сервера» → под переключателем «Использовать
прокси-сервер» будут IP-адрес и порт. Формат для `.env`:

```
TELEGRAM_PROXY_URL=socks5://127.0.0.1:10808
```

(адрес и порт — свои, из настроек Windows; если там `socks=127.0.0.1`, в `.env`
пиши `socks5://127.0.0.1:порт`). Если Telegram открывается и без прокси — оставь
эту строку пустой.

## 7. Запуск

```powershell
cd путь\к\tg-schedule-bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app
```

Первая команда создаёт изолированное окружение, вторая его включает, третья ставит библиотеки,
четвёртая запускает бота. При каждом следующем запуске нужны только вторая и четвёртая.

Пока окно PowerShell открыто — бот жив. Закрыл окно — бот выключился. Это нормально на время
разработки; на постоянную работу его переселим на сервер на этапе 7.

## Как работать с Claude Code

Открой PowerShell в папке проекта и выполни `claude`.

Первый запуск:

```
Прочитай CLAUDE.md и docs/PLAN.md. Используй агента pm. Начинаем этап 1.
```

Дальше на каждом этапе:

```
Используй агента pm. Начинаем этап 2.
```

Когда что-то сломалось — не пересказывай своими словами, **скопируй текст ошибки целиком**:

```
Используй агента debugger. Вот ошибка: <вставь текст>
```

Когда этап вроде готов:

```
Используй агента tester. Проверь этап 3 и дай чек-лист ручной проверки.
```

Три вещи, которые сильно экономят время:

- Не проси «сделай весь бот сразу». Модель уйдёт в простыню кода, где невозможно найти ошибку.
- После каждого этапа делай коммит: `git add -A` и `git commit -m "этап 2"`. Тогда всегда
  есть точка, куда откатиться.
- Если ответ непонятен — так и напиши: «объясни проще, я не программист». Это нормальный запрос.
