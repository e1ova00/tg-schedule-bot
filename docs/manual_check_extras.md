# Ручная проверка. Доработка: `/day`, `/week`, `/teachernote`, `/addnote`

Что проверяем — четыре новые возможности сверх плана:

| Команда | Зачем |
|---|---|
| `/day 2026-09-15` | расписание на **любую** дату, а не только сегодня и завтра |
| `/week` | вся неделя одним сообщением, листается кнопками вперёд и назад |
| `/teachernote` | заметки **про преподавателя**: что помнить о человеке (без напоминаний) |
| `/addnote` | заметка к **любой** паре в любой момент, не дожидаясь вопроса после пары |

Пройти всё целиком — минут 30. Из них минут 20 в конце — ожидание: последняя проверка
(пункт 33) требует дождаться, когда закончится одна конкретная пара. Её можно отложить
на любой учебный день, всё остальное проверяется сразу.

Команды с приставкой «в PowerShell» вводятся в чёрном окне PowerShell
(клавиша Win → набрать `powershell` → Enter), их можно копировать целиком и вставлять
правой кнопкой мыши. На macOS/Linux те же команды работают в Терминале, отличия помечены.
Все остальные команды вводятся **в Telegram, в чате с ботом**.

Если на каком-то шаге получилось не то, что написано в «Должно получиться», — дальше
не иди, а действуй по пункту 38.

```powershell
python -m pytest -q
```

Эта команда проверяет всю логику без Telegram: разбор даты, границы листания недели,

последующий вопрос «Есть / Нет» по той же паре.

**Должно получиться:** последняя строка вида `1397 passed` (число растёт от доработки
к доработке, точная цифра неважна) и ни одного слова `failed`.

### 3. Запусти бота

```powershell

```

**Должно получиться:** в окне появились строки «Бот запущен: @имя_твоего_бота»,
«Планировщик будильников запущен...», «Планировщик заметок запущен...».
Окно не закрывай: пока оно открыто, бот живой.

### 4. Посмотри список команд


## Часть 2. `/day` — расписание на любую дату

### 6. Без даты

```
/day
```

**Должно получиться:** ровно то же самое сообщение, что и на `/today`: заголовок
«Сегодня, <день недели>, <число>» и список пар (или «Сегодня пар нет»).

### 7. С конкретной датой

```
/day 2026-09-15
```

**Должно получиться:** заголовок «Вторник, 15 сентября», под ним «Неделя — числитель»
и три пары: 11:40 Безопасность жизнедеятельности, 13:45 Безопасность жизнедеятельности,
15:20 Администрирование вычислительных систем и сетей.

### 8. Пустой день — это нормальный ответ, а не ошибка

```
/day 2026-09-03
```

**Должно получиться:** «Четверг, 3 сентября», «Неделя — числитель», «Пар нет — можно
выдохнуть.» По числителю четверг у группы действительно пустой.

Для сравнения — тот же четверг через неделю:

```
/day 2026-09-10
```

**Должно получиться:** «Неделя — знаменатель» и три пары. То есть чётность бот считает
по самой дате, а не по «сегодня».

### 9. Понедельник — весь дистанционный

```
/day 2026-09-14
```

**Должно получиться:** три пары, и у каждой вместо адреса написано «дистанционно».
Ни одного корпуса и ни одного номера аудитории в этом дне быть не должно.

### 10. Непонятная дата

```
/day завтра
```

**Должно получиться:** «Не понял дату «завтра». Пришли её в виде ГГГГ-ММ-ДД, например
/day 2026-09-15. Без даты я покажу сегодняшний день.»

Проверь ещё два варианта — ответ должен быть таким же вежливым, а не «ошибка» и не молчание:

```
/day 15.09.2026
```

```
/day 2026-02-29
```

(29 февраля бывает не каждый год, 2026-й — не тот.)

## Часть 3. `/week` — вся неделя и листание

### 11. Текущая неделя

```
/week
```

**Должно получиться:** одно сообщение, а в нём:

* заголовок «Неделя <число> — <число>» и строка «Это числитель.» либо «Это знаменатель.»;
* **шесть** блоков: понедельник, вторник, среда, четверг, пятница, суббота.
  Воскресенья быть не должно — пар в этот день не бывает вообще;
* у сегодняшнего дня к заголовку приписано «— сегодня» (если сегодня воскресенье, приписки
  не будет — это нормально);
* под сообщением две кнопки: «← Предыдущая» и «Следующая →».

### 12. Пустые дни видно и в обзоре недели

**Должно получиться:** в неделе-числителе под словом «Четверг» написано «пар нет»,
а в неделе-знаменателе то же самое написано под «Пятница» и «Суббота». Остальные дни —
со списком пар.

Если сейчас числитель, знаменатель посмотришь на следующем шаге, и наоборот.

### 13. Нажми «Следующая →»

**Должно получиться — это самое важное в этой части:** сообщение **изменилось на месте**.
Новое сообщение внизу чата появиться не должно: в чате по-прежнему одно сообщение с
расписанием, просто в нём теперь другая неделя.

Проверь заодно:

* даты в заголовке сдвинулись ровно на 7 дней вперёд;
* слово в строке «Это ...» поменялось: числитель ↔ знаменатель;
* пометки «— сегодня» больше нет (мы ушли из текущей недели).

### 14. Нажми «Следующая →» ещё четыре раза

**Должно получиться:** каждый раз то же самое сообщение, каждый раз плюс 7 дней,
и «числитель» со «знаменателем» ровно чередуются. Ни одного нового сообщения в чате.

### 15. Нажми «← Предыдущая» пять раз

**Должно получиться:** вернулись ровно туда, откуда начали: та же неделя, что была
в пункте 11, и снова видна пометка «— сегодня».

### 16. Неделя по дате

```
/week 2026-09-15
```

**Должно получиться:** «Неделя 14 сентября — 19 сентября», «Это числитель.»
То есть бот показывает не сам день, а всю неделю, в которую этот день попадает.

Проверь, что любой день недели даёт одну и ту же неделю:

```
/week 2026-09-19
```

**Должно получиться:** ровно тот же самый текст, что и на предыдущей команде.

### 17. Непонятная дата у `/week`

```
/week послезавтра
```

**Должно получиться:** «Не понял дату «послезавтра»... Без даты — текущая неделя.»
Кнопок листания под этим ответом быть не должно.

### 18. Край диапазона: дальше года бот не листает

Узнай дату ровно через 52 недели — **в PowerShell**:

```powershell
python -c "import datetime; d=datetime.date.today(); m=d-datetime.timedelta(days=d.weekday()); print('/week', (m+datetime.timedelta(weeks=52)).isoformat())"
```

Команда напечатает строку вида `/week 2027-09-06`. Скопируй её целиком и отправь боту.

**Должно получиться:** неделя показалась, но под сообщением осталась **только одна**
кнопка — «← Предыдущая». Кнопки «Следующая →» нет: дальше это уже другой учебный год,
и листать туда бот не даёт.

То же самое назад:

```powershell
python -c "import datetime; d=datetime.date.today(); m=d-datetime.timedelta(days=d.weekday()); print('/week', (m-datetime.timedelta(weeks=52)).isoformat())"
```

**Должно получиться:** осталась только кнопка «Следующая →».

> Отдельная всплывашка «Дальше листать не буду — это уже совсем другой учебный год»
> задумана для очень старых сообщений: кнопку за краем бот не рисует, поэтому нажать её
> можно только в сообщении, которое пролежало в чате больше года. Руками это не
> воспроизвести — такой случай закрыт тестами.

## Часть 4. `/teachernote` — заметки про преподавателей

### 19. Открой команду

```
/teachernote
```

**Должно получиться:** сообщение «Заметки про преподавателей» с объяснением, что
напоминаний по таким заметкам нет, и две кнопки: «Добавить заметку», «Посмотреть все».

### 20. Нажми «Посмотреть все», пока ничего не добавлено

**Должно получиться:** «Заметок про преподавателей пока нет. Добавить — /teachernote,
кнопка «Добавить заметку».» Никаких пустых списков и никаких ошибок.

### 21. Нажми «Добавить заметку»

Сначала снова открой `/teachernote`, потом нажми первую кнопку.

**Должно получиться:** «Про кого запишем? Выбери кнопкой...» и **десять** кнопок с
фамилиями, по две в ряд, по алфавиту:

```
Агеева Е.А.      Бельченко А.Г.
Волков А.И.      Зверев В.В.
Кокорин Е.С.     Маньков В.Д.
Николаева Л.Г.   Прохорова А.А.
Савенкова П.В.   Шевякова А.Р.
```

Ввести фамилию руками нельзя, и это сделано нарочно: иначе «Зверев» и «Зверев В.В.»
стали бы разными людьми и заметки разъехались бы.

### 22. Нажми «Зверев В.В.»

**Должно получиться:** кнопки исчезли, бот ответил:

```
Зверев В.В.

Напиши одним сообщением, что запомнить про этого преподавателя.

Передумал — /cancel.
```

### 23. Напиши текст

```
принимает работы только на почту, в pdf
```

**Должно получиться:** «Записал — заметка про **Зверев В.В.** сохранена. Посмотреть все
заметки — /teachernote.»

### 24. Добавь вторую заметку — про другого человека

Повтори пункты 21–23, но выбери «Агеева Е.А.» и напиши что-нибудь своё, например
`спрашивает по всем лекциям сразу`.

### 25. Посмотри список

```
/teachernote
```

и нажми «Посмотреть все».

**Должно получиться:** заголовок «Заметки про преподавателей», а под ним список,
сгруппированный по людям, фамилии по алфавиту:

```
Агеева Е.А.
• спрашивает по всем лекциям сразу

Зверев В.В.
• принимает работы только на почту, в pdf
```

### 26. Проверь `/cancel` внутри этой команды

`/teachernote` → «Добавить заметку» → любая фамилия. Вместо текста отправь:

```
/cancel
```

**Должно получиться:** ровно «Хорошо, ничего не записал.»

Важно: ответ должен быть **именно такой**. Если пришло «Хорошо, остановились. Всё, что
успел ответить, я сохранил» — это текст из диалога знакомства, значит команды
перепутались, зови `debugger` (пункт 38).

Проверь, что заметка действительно не сохранилась: `/teachernote` → «Посмотреть все» —
в списке должны остаться только те две, что из пунктов 23 и 24.

### 27. Убедись, что напоминаний по таким заметкам нет

```
/notes
```

**Должно получиться:** в списке заметок по парам заметок про преподавателей нет — это
две разные вещи. Зато в самом конце `/notes` есть строчка-подсказка про `/teachernote`.

## Часть 5. `/addnote` — заметка к любой паре заранее

### 28. Открой команду

```
/addnote
```

**Должно получиться:** «К паре какого дня добавить заметку?» и две кнопки:
«Сегодня», «Завтра».

### 29. Дата текстом тоже работает

Вместо нажатия кнопки напиши сообщением:

```
2026-09-15
```

**Должно получиться:** «Вторник, 15 сентября. К какой паре относится заметка?» и три
кнопки с парами этого дня, каждая вида `11:40 · Безопасность жизнедеятельности`.
Длинные названия предметов на кнопке обрезаны многоточием — так и задумано.

Пока ничего не выбирай, просто убедись, что кнопки есть.

### 30. Пустой день

```
/addnote 2026-09-03
```

**Должно получиться:** «3 сентября — пар нет, привязывать заметку не к чему.
Попробуй другой день: /addnote.» Кнопок нет, текст заметки бот не ждёт.

### 31. Непонятная дата

```
/addnote
```

и в ответ на вопрос про день напиши `вчера`.

**Должно получиться:** «Не понял дату «вчера». Нужен формат ГГГГ-ММ-ДД... или просто
нажми кнопку.» Диалог при этом не обрывается: можно тут же прислать нормальную дату
или нажать кнопку. Выйти — `/cancel`, ответ «Хорошо, заметку не добавляю.»

### 32. Полный цикл: добавь заметку к сегодняшней паре, которая ещё не началась

Сначала посмотри, что сегодня:

```
/today
```

Выбери пару, которая **сегодня ещё не закончилась** (лучше — которая ещё даже не
началась) и запиши её время окончания, оно понадобится в пункте 33.

> Если сегодня пар нет или все уже прошли — отложи пункты 32–34 до ближайшего учебного
> дня. Числитель: во вторник, среду, пятницу и субботу пары есть. Знаменатель: в понедельник,
> вторник, среду и четверг.

Дальше:

```
/addnote
```

Нажми кнопку «Сегодня».

**Должно получиться:** заголовок с сегодняшней датой и кнопки со всеми сегодняшними
парами — включая дистанционные (домашку задают и на них).

Нажми кнопку с выбранной парой.

**Должно получиться:** кнопки исчезли, бот просит текст — тем же самым сообщением, что и
при обычном вопросе после пары:

```
Напиши одним сообщением, что задали — своими словами, как удобно.

Я привяжу запись к этой паре и напомню за сутки до следующей. Передумал — /cancel.
```

Напиши текст, например:

```
проверка addnote: принести флешку
```

**Должно получиться:** «Записал. Напомню <дата> — за сутки до пары, и утром в день пары.»
Дата — это следующая такая же пара: через неделю, если пара идёт каждую неделю, и через
две, если она только по числителю или только по знаменателю.

### 33. Проверь, что заметка попала в общий список

```
/notes
```

**Должно получиться:** в разделе «Незакрытые заметки» есть запись «проверка addnote:
принести флешку» с датой и временем той самой пары и с кнопкой «Сделал».
То есть заметка из `/addnote` — самая обычная заметка, никакой отдельной полки для неё нет.

### 34. Главная проверка: вопрос «Есть / Нет» по этой паре больше не придёт

Дождись момента **через 10 минут после окончания** выбранной пары (бот всё это время
должен быть запущен — окно PowerShell открыто).

**Должно получиться:** по этой паре бот молчит. Вопрос «Пара закончилась: ... Есть что
записать?» с кнопками «Есть / Нет» приходить **не должен** — заметка по ней уже есть,
и переспрашивать незачем.

А вот по **другим** парам этого дня вопросы приходят как обычно — проверь на следующей
паре дня, если она есть. Если бот молчит вообще по всем парам — это уже подозрительно,
зови `debugger`.

> Если ты перезапустил бота после пункта 32, результат тот же: при старте бот
> пересчитывает вопросы на день и по этой паре его просто не ставит. В окне PowerShell
> в этом случае не будет строки «Вопрос про домашку по паре ... поставлен на ...»
> именно для неё.

```
/today
```

```
/tomorrow
```

дистанционный»).

### 36. Заметки по парам

```
/notes
```

**Должно получиться:** список работает, кнопки периодов «За неделю» и «Все»
переключают его, кнопка «Сделал» закрывает заметку.

### 37. Наведи порядок после проверки

Заметки, созданные в пунктах 23, 24 и 32, можно оставить — они никому не мешают.
Если хочется убрать именно проверочные, останови бота (`Ctrl + C` в окне PowerShell) и
выполни **в PowerShell**:

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/bot.db'); n=c.execute('DELETE FROM notes WHERE text LIKE ?', ('проверка addnote%',)).rowcount; t=c.execute('DELETE FROM teacher_notes WHERE text LIKE ? OR text LIKE ?', ('принимает работы только на почту%','спрашивает по всем лекциям%')).rowcount; c.commit(); c.close(); print('Удалено заметок по парам:', n, ', про преподавателей:', t)"
```

Команда открывает файл базы бота и удаляет только записи с этими текстами. Настройки,
расписание и остальные заметки она не трогает.

Запусти бота обратно:

```powershell
python -m app
```

## Часть 7. Если что-то пошло не так

### 38. Как позвать помощь

Не чини сам. Собери три вещи:

1. **номер пункта** этого чек-листа, на котором получилось не то;
2. **что бот ответил** — скриншот или скопированный текст;
3. **последние 20 строк** из окна PowerShell, где запущен бот (выдели мышью, нажми Enter —
