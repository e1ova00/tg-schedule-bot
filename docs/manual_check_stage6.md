# Ручная проверка. Этап 6 «Заметки и дедлайны»

Что проверяем: бот сам, через **10 минут после каждой пары**, спрашивает «есть что записать?».
Если есть — запоминает текст и привязывает его **к этой конкретной паре этого числа**
(а не к предмету вообще). Потом напоминает: **за сутки** до следующей такой же пары
и ещё раз **утром в день пары**, пока ты не нажмёшь «Сделал».

Полный цикл, который надо пройти руками (это и есть критерий приёмки этапа):

```
вопрос после пары → «Есть» → написал текст → увидел в /notes →
получил напоминание → нажал «Сделал» → заметка закрылась
```

Займёт минут 40, из них минут 30 — ожидание напоминаний (в это время можно заниматься
своими делами, бот сам напишет).

Команды вводятся в **PowerShell** (клавиша Win → набрать `powershell` → Enter),
их можно копировать целиком и вставлять правой кнопкой мыши. На macOS/Linux команды те же,
отличия помечены отдельно.

Этапы 3 и 5 должны быть пройдены (`docs/manual_check_stage3.md`,
`docs/manual_check_stage5.md`): бот тебя знает, `/settings` показывает твои ответы,
`/preview` считает подъём. Если `/settings` отвечает «Мы ещё не закончили знакомство» —
сначала пройди `/start` до конца.

## Часть 2. Вопрос «Есть / Нет» после пары

Бот спрашивает про домашку через 10 минут после **каждой** пары дня — и после очной,
и после дистанционной (задать могут на любой).

### 5. Узнай, когда бот спросит сегодня

```
/today
```

**Должно получиться:** список сегодняшних пар. Прибавь **10 минут** к времени окончания
любой из них — это и есть момент вопроса.

Для сверки, во сколько бот спрашивает в каждый день недели:

| День | Числитель — вопросы придут в | Знаменатель — вопросы придут в |
|---|---|---|
| понедельник | 11:40, 15:20, 16:55 | 13:15, 15:20, 16:55 |
| вторник | 13:15, 15:20, 16:55 | 13:15, 15:20 |
| среда | 11:40, 13:15, 15:20 | 11:40, 13:15, 15:20, 16:55 |
| четверг | пар нет | 13:15, 15:20, 18:30 |
| пятница | 11:40, 13:15, 16:55 | пар нет |
| суббота | 18:30 | пар нет |
| воскресенье | пар нет | пар нет |

Какая сейчас неделя, бот пишет в заголовке `/today`: «Неделя — числитель» или
«Неделя — знаменатель».

### 6. Дождись ближайшего момента из таблицы

Бот должен быть запущен **до** этого времени: вопрос ставится в очередь при старте,
задним числом бот его не досылает (спрашивать «что задали?» через три часа после пары —
это уже не помощь, а спам).

**Должно получиться:** ровно в указанную минуту в Telegram приходит

```
Пара закончилась: Web-дизайн (13:45–15:10).

Есть что записать — домашка, что принести, к чему подготовиться?
       [ Есть ]   [ Нет ]
```

> **Если сегодня пар нет или все уже прошли** — это нормально, вопрос не придёт.
> Тогда пройди пункты 7–9 в ближайший учебный день, а остальные части чек-листа
> можно проверить прямо сейчас: в пункте 11 есть команда, которая создаёт заметку
> без ожидания пары.

### 7. Нажми «Нет»

**Должно получиться:** кнопки под сообщением исчезли, бот ответил одной строкой
«Понял, ничего не записываю». Больше он на эту пару не переспрашивает.

### 8. Дождись следующего вопроса и нажми «Есть»

**Должно получиться:** бот просит текст:

```
Напиши одним сообщением, что задали — своими словами, как удобно.

Я привяжу запись к этой паре и напомню за сутки до следующей. Передумал — /cancel.
```

### 9. Напиши текст заметки

Отправь обычным сообщением, например:

```
доделать макет и принести флешку
```

**Должно получиться:** ответ вида

```
Записал. Напомню 16 сентября — за сутки до пары, и утром в день пары.
```

Дата в ответе — это **следующая такая же пара**: через неделю, если пара идёт каждую
неделю, и через две недели, если пара только по числителю или только по знаменателю.
Проверить можно так: открой `/today` в названный день — эта пара там должна быть.

### 10. Проверь, что `/cancel` отменяет именно заметку

Дождись ещё одного вопроса (или повтори пункт 8 в следующий раз), нажми «Есть»,
а вместо текста напиши:

```
/cancel
```

**Должно получиться:** «Хорошо, ничего не записал. Заметку можно добавить и позже.»
Важно: ответ должен быть **именно такой**, а не «Хорошо, остановились. Всё, что успел
ответить, я сохранил» — второй текст относится к диалогу знакомства, и если пришёл он,
значит команды перепутались. Тогда зови `debugger`.

## Часть 3. Список заметок `/notes`

### 11. Если заметки ещё нет — создай её командой

Этот пункт нужен, только если ты не дождался вопроса после пары (пункт 6). Останови бота
(`Ctrl + C` в окне PowerShell) и выполни:

```powershell
python -c "import sqlite3,datetime; c=sqlite3.connect('data/bot.db'); uid=c.execute('SELECT telegram_id FROM users ORDER BY telegram_id LIMIT 1').fetchone()[0]; now=datetime.datetime.now().astimezone().isoformat(timespec='seconds'); today=datetime.date.today(); c.execute('INSERT INTO notes (telegram_id, lesson_id, lesson_date, due_date, text, status, created_at) VALUES (?,?,?,?,?,?,?)', (uid, 'L1223', today.isoformat(), (today+datetime.timedelta(days=1)).isoformat(), 'проверочная заметка', 'open', now)); c.commit(); c.close(); print('Заметка создана для пользователя', uid)"
```

Эта команда открывает файл базы бота и добавляет туда одну заметку «проверочная заметка»
по паре Web-дизайн, со сроком «завтра». Ничего другого она не трогает: ни настройки,
ни расписание. В пункте 23 написано, как её потом удалить.

Запусти бота обратно:

```powershell
python -m app
```

### 12. Открой список

```
/notes
```

**Должно получиться:** несколько сообщений подряд:

```
Незакрытые заметки

2 сентября, 13:45–15:10 — Web-дизайн
доделать макет и принести флешку
Спросят 9 сентября.
       [ Сделал ]

Показать другой период:
       [ За неделю ]   [ Все ]
```

Проверь три вещи:

- дата и время сверху — это **та самая пара**, после которой ты писал заметку;
- строка «Спросят ...» — это дата следующей такой же пары;
- под незакрытой заметкой есть кнопка «Сделал».

### 13. Проверь период «За неделю»

Нажми кнопку **«За неделю»**.

**Должно получиться:** заголовок «Заметки за эту неделю» и список тех заметок, чьи пары
были на этой неделе (неделя считается с понедельника по воскресенье). Если на этой неделе
заметок не было — текст «На этой неделе заметок не было.»

### 14. Проверь период «Все»

Нажми кнопку **«Все»**.

**Должно получиться:** заголовок «Все заметки» и список всех твоих заметок, включая уже
закрытые. Закрытые помечены галочкой ✅ и строкой «Закрыта.», кнопки «Сделал» под ними нет.
Если заметок нет вовсе — «Заметок пока нет. Я спрошу про домашку сам — через десять минут
после пары.»

### 15. Вернись к «Незакрытым»

Нажми кнопку **«Незакрытые»**.

**Должно получиться:** заголовок «Незакрытые заметки». Каждый из трёх периодов даёт **свой**
заголовок и свой текст «пусто» — если тексты одинаковые, что-то не так.

## Часть 4. Напоминание за сутки, не дожидаясь суток

Напоминание приходит ровно за 24 часа до начала следующей такой пары. Ждать сутки не надо:
достаточно подвинуть у заметки поле «срок» — как в этапе 5 мы двигали время на сборы.

### 16. Выбери, на какую пару «повесить» срок

Посмотри на часы и найди свою строку:

| Сейчас на часах | Номер пары для команды | Напоминание придёт сегодня в | Про какую пару будет текст |
|---|---|---|---|
| раньше 10:00 | `L1221` | 10:05 | Прикладной дизайн |
| 10:05 – 11:35 | `L1216` | 11:40 | Безопасность жизнедеятельности |
| 11:40 – 13:40 | `L1223` | 13:45 | Web-дизайн |
| 13:45 – 15:15 | `L1231` | 15:20 | Информационные системы и технологии |
| 15:20 – 16:50 | `L1227` | 16:55 | Безопасность жизнедеятельности |
| позже 16:55 | — | сегодня уже никак | сделай этот пункт завтра днём |

Смысл строки: срок заметки станет «завтра, эта пара», а напоминание за сутки — «сегодня,
в то же время».

### 17. Сдвинь срок последней заметки

Останови бота (`Ctrl + C`) и выполни команду, подставив свой номер пары из таблицы
вместо `L1223` (менять надо только его, в одном месте):

```powershell
python -c "import sqlite3,datetime; c=sqlite3.connect('data/bot.db'); d=(datetime.date.today()+datetime.timedelta(days=1)).isoformat(); c.execute('UPDATE notes SET lesson_id=?, due_date=? WHERE id=(SELECT MAX(id) FROM notes)', ('L1223', d)); c.commit(); c.close(); print('Готово: срок последней заметки — завтра, эта пара')"
```

Команда меняет у **последней созданной** заметки пару и срок. Больше она ничего не трогает.

### 18. Запусти бота и убедись, что напоминание запланировано

```powershell
python -m app
```

**Должно получиться:** в окне бота есть строка вида

```
Напоминание «day_before» по заметке 1 поставлено на 2026-09-09T13:45+03:00
```

Время в этой строке = начало пары **минус 24 часа**, то есть сегодняшнее время из таблицы
пункта 16. Уже одна эта строка доказывает, что расчёт «за сутки» работает.

Рядом будет вторая строка, `Напоминание «morning» ... поставлено на ...` с завтрашним
числом и временем из `NOTES_MORNING_TIME` — это уже утренний повтор, им займёмся в части 5.

### 19. Дождись самого напоминания

**Должно получиться:** в назначенную минуту приходит сообщение

```
Завтра в 13:45 — Web-дизайн.

По этой паре записано: доделать макет и принести флешку
       [ Сделал ]   [ Не сделал ]
```

Проверь: время и предмет — те, что ты выбрал в пункте 16; текст заметки — твой; **обе**
кнопки на месте.

### 20. Нажми «Не сделал»

**Должно получиться:** кнопки исчезли, бот ответил

```
Хорошо, напомню ещё раз утром.
```

Заметка при этом **не закрылась** — проверь через `/notes`, она должна остаться в
«Незакрытых». Тон ответа спокойный: ни «опять», ни «снова», ни «надо было раньше».
Если бот написал что-то укоризненное — это ошибка этапа, зови `debugger`.

## Часть 5. Утренний повтор, не дожидаясь утра

Утром в день пары бот повторяет напоминание по всем незакрытым заметкам. Время повтора
задаётся в `.env` строкой `NOTES_MORNING_TIME` (по умолчанию `08:00`) — её и подвинем.

Этот пункт удобно делать **до 15:45**: повтор не отправляется, если до самой пары осталось
меньше часа (в этом случае напоминать второй раз — просто давить), а самая поздняя пара
начинается в 16:55.

### 21. Сдвинь срок на сегодня и время повтора на «через 3 минуты»

Останови бота (`Ctrl + C`) и выполни три команды по очереди.

Первая — переносит срок заметки на сегодня, на пару в 16:55:

```powershell
python -c "import sqlite3,datetime; c=sqlite3.connect('data/bot.db'); c.execute('UPDATE notes SET lesson_id=?, due_date=? WHERE id=(SELECT MAX(id) FROM notes)', ('L1227', datetime.date.today().isoformat())); c.commit(); c.close(); print('Готово: срок последней заметки — сегодня, пара в 16:55')"
```

Вторая — убирает отметки «такое напоминание уже уходило», иначе бот справедливо промолчит:

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/bot.db'); c.execute('DELETE FROM note_reminder_log'); c.commit(); c.close(); print('Отметки об отправленных напоминаниях убраны')"
```

Третья — подскажет, какое время вписать в `.env`:

```powershell
python -c "import datetime; print('NOTES_MORNING_TIME=' + (datetime.datetime.now()+datetime.timedelta(minutes=3)).strftime('%H:%M'))"
```

Открой файл `.env` в «Блокноте» и впиши туда напечатанную строку (если строка
`NOTES_MORNING_TIME=` там уже есть — просто замени время). Сохрани файл.

### 22. Запусти бота и дождись повтора

```powershell
python -m app
```

**Должно получиться:** через те самые 3 минуты приходит

```
Доброе утро! Сегодня в 16:55 — Безопасность жизнедеятельности.

По этой паре записано: доделать макет и принести флешку
       [ Сделал ]
```

Отличия от вчерашнего напоминания: слова «Сегодня» вместо «Завтра» и **только одна**
кнопка — «Сделал». Так и задумано: повторять уже нечем, поэтому кнопки «Не сделал» здесь нет.

Нажми **«Сделал»**.

**Должно получиться:** всплывающая подсказка «Готово», кнопка исчезла, бот ответил
«Отлично, закрыл заметку.» Открой `/notes` — заметки в «Незакрытых» больше нет, а в
периоде «Все» она есть с галочкой ✅ и подписью «Закрыта.»

**Верни `.env` как было:** впиши `NOTES_MORNING_TIME=08:00` (или своё обычное значение)
и перезапусти бота. Иначе завтра утренние напоминания придут не вовремя.

## Часть 6. Перезапуск ничего не задваивает

Задачи бота живут в памяти и пересчитываются при каждом запуске, поэтому важно проверить,
что перезапуск не приводит к повторным вопросам и напоминаниям.

### 23. Перезапусти бота два раза подряд

В окне PowerShell: `Ctrl + C`, затем `python -m app`. Подожди минуту, снова `Ctrl + C`
и `python -m app`.

**Должно получиться:**

- **не приходит** повторный вопрос «Есть / Нет» по паре, про которую сегодня уже спрашивали;
- **не приходит** повторное напоминание по заметке, по которой оно сегодня уже уходило;
- в окне бота при втором запуске **больше нет** строки
  `Вопрос про домашку по паре L1223 (...) поставлен на ...` — бот видит в своём журнале,
  что уже спрашивал, и задачу не ставит;
- если напоминание всё же успело сработать повторно, в логе будет строка
  `Напоминание «morning» по заметке 1 уже уходило` — и сообщение при этом не уйдёт.

Если после перезапуска пришло второе такое же сообщение — это ошибка, зови `debugger`.

### 24. Убери проверочные заметки

Когда всё проверено, останови бота (`Ctrl + C`) и удали тестовые записи:

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/bot.db'); c.execute('DELETE FROM notes'); c.execute('DELETE FROM note_reminder_log'); c.execute('DELETE FROM note_prompt_log'); c.commit(); c.close(); print('Проверочные заметки и журналы очищены')"
```

Команда стирает **все** заметки и оба журнала. Настройки, расписание и журнал будильников
она не трогает. После неё запусти бота обратно: `python -m app`.

Если хочешь просто посмотреть, что лежит в заметках, не удаляя:

```powershell
python -c "import sqlite3; c=sqlite3.connect('data/bot.db'); [print(r) for r in c.execute('SELECT id, lesson_id, lesson_date, due_date, status, text FROM notes ORDER BY id')]; c.close()"
```

## Часть 7. Мелочи, которые тоже стоит проверить

### 25. Спецсимволы в тексте заметки

Заведи заметку с текстом, в котором есть угловые скобки и амперсанд:

```
сверстать <div> & проверить 3<5
```

**Должно получиться:** заметка сохранилась, `/notes` показывает текст **как есть**
(`сверстать <div> & проверить 3<5`), бот не молчит и не падает. Сообщения уходят в
формате HTML, поэтому такие символы бот специально обезвреживает — если вместо текста
пришла ошибка или часть текста пропала, зови `debugger`.

### 26. Старая кнопка

Нажми кнопку «Сделал» под заметкой, которую уже закрыл (например, в периоде «Все»
её нет, но старое сообщение с кнопкой могло остаться выше в переписке).

**Должно получиться:** всплывашка «Эта заметка уже закрыта.» или «Такой заметки у меня
нет — возможно, кнопка от старого сообщения.» Бот не падает, окно продолжает работать.

### 27. Дни без пар

В четверг по числителю, в пятницу и субботу по знаменателю и в любое воскресенье вопросов
про домашку быть не должно вовсе — пар нет, спрашивать не о чем.

**Должно получиться:** телефон молчит, а в `logs/bot.log` нет строк
`Вопрос про домашку ... поставлен`. Это не поломка.

### 28. Понедельник

Понедельник у группы полностью дистанционный: **будильника нет, а вопросы про домашку
есть**. Это разное поведение, и так и задумано — задание могут дать и на дистанционной паре.

**Должно получиться:** в понедельник в 11:40 / 15:20 / 16:55 (числитель) приходят вопросы
«Есть / Нет», а утреннего «⏰ Доброе утро» нет.

## Часть 8. Если что-то пошло не так

### 29. Таблица частых случаев

| Что видно | Что это значит |
|---|---|
| Вопрос после пары не пришёл, хотя пара была | бот был выключен в этот момент — задним числом он не спрашивает, это осознанное решение |
| Вопрос пришёл, но с опозданием на пару минут | нормально: у задачи есть полчаса форы на занятый компьютер |
| Вопрос не пришёл в четверг (числитель) / пятницу и субботу (знаменатель) | пар нет — спрашивать не о чем |
| Вопрос пришёл дважды по одной паре | это ошибка — зови `debugger`, приложи оба сообщения и `logs/bot.log` |
| «Записал. Следующего такого занятия в расписании не нашёл...» | у пары нет следующего занятия в ближайшие два месяца: заметка сохранена, но напоминаний не будет |
| Напоминание за сутки не пришло | посмотри лог: есть ли строка «Напоминание «day_before» ... поставлено на ...». Если бот был выключен в тот момент — напоминание пропускается намеренно, задним числом «завтра пара» не шлётся |
| Утренний повтор не пришёл | так бывает, если до пары остаётся меньше часа от `NOTES_MORNING_TIME` — тогда повтор не нужен |
| Нажал «Сделал», а заметка осталась | это ошибка — зови `debugger`, приложи скриншот и `logs/bot.log` |
| «Такой заметки у меня нет» на своей заметке | это ошибка — зови `debugger` |
| В окне бота красный текст со словом `Traceback` | скопируй последние 20 строк и зови `debugger` |

### 30. Где смотреть логи

```powershell
Get-Content logs\bot.log -Tail 50
```

(на macOS/Linux: `tail -n 50 logs/bot.log`)

Полезные строки этапа 6:

- `Планировщик заметок запущен, пересчёт каждый день в 05:00 по Москве` — планировщик жив;
- `Вопрос про домашку по паре L1223 (2026-09-09) поставлен на 2026-09-09T15:20+03:00, ждут 1 человек` — вопрос в очереди;
- `Вопрос про домашку по L1223 (2026-09-09) опоздал на ..., пропускаю` — бот осознанно промолчал;
- `Заметка 3 создана: пользователь=123456789 пара=L1223 (2026-09-09), срок=2026-09-16` — заметка сохранена;
- `Напоминание «day_before» по заметке 3 поставлено на 2026-09-15T13:45+03:00` — напоминание в очереди;
- `Напоминание «day_before» по заметке 3 уже уходило` — защита от повторов работает;
- `Напоминание «morning» по заметке 3 отправлено` — сообщение ушло;
- `Заметка 3 закрыта пользователем ...` — кнопка «Сделал» сработала.

### 31. Как передать проблему

Скопируй текст ошибки или сделай скриншот переписки, открой Claude Code в папке проекта
командой `claude` и напиши:

```
Используй агента debugger. Этап 6, пункт N чек-листа. Ожидал: <что должно быть>.
Получил: <что пришло на самом деле>.
```

К сообщениям про заметки обязательно приложи: скриншот переписки, вывод команды из
пункта 24 (список заметок) и последние 30 строк `logs/bot.log`.

## Итог

Этап 6 принят, если:

- тесты зелёные (пункт 2);
- после пары приходит вопрос «Есть / Нет», и «Нет» ничего не сохраняет (пункты 6–7);
- «Есть» → текст → заметка сохранена и привязана к нужной паре и дате, а срок — это дата
  следующей такой же пары (пункты 8–9);
- `/cancel` во время ввода текста отменяет именно заметку (пункт 10);
- `/notes` показывает заметку и переключается между тремя периодами, у каждого свой
  заголовок и свой текст «пусто» (пункты 12–15);
- напоминание за сутки приходит с кнопками «Сделал / Не сделал», «Не сделал» ничего не
  закрывает и отвечает спокойно (пункты 19–20);
- утренний повтор приходит с одной кнопкой «Сделал», и она действительно закрывает заметку
  (пункт 22);
- после перезапуска бота ни вопросы, ни напоминания не задваиваются (пункт 23).
