# Ручная проверка. Этап 2 «Расписание и чётность»

Что проверяем: бот правильно считает числитель/знаменатель, показывает пары на сегодня
и на завтра, честно пишет «пар нет» в пустые дни и помечает дистанционные пары.

Займёт минут 15. Иди строго по пунктам сверху вниз. Команды вводятся в **PowerShell**
(клавиша Win → набрать `powershell` → Enter), их можно копировать и вставлять правой
кнопкой мыши. На macOS/Linux команды те же, отличия помечены отдельно.

Этап 1 должен быть уже пройден (см. `docs/manual_check_stage1.md`): бот запускается
и отвечает на `/start`.

## Часть 1. Автоматические тесты

### 1. Открой папку проекта и включи окружение

```powershell
cd путь\к\tg-schedule-bot
.venv\Scripts\activate
```

(на macOS/Linux вторая строка: `source .venv/bin/activate`)

**Должно получиться:** в начале строки появилась приписка `(.venv)`.

### 2. Прогони тесты

```powershell
python -m pytest -q
```

Эта команда проверяет логику расписания без Telegram: контрольные даты чётности,
пустые дни, понедельник, выбор корпуса.

**Должно получиться:** последняя строка вида `231 passed in 2.4s`. Слов `failed`
и `error` быть не должно. Строчка про `PytestDeprecationWarning` — не ошибка,
её игнорируем.

Если написано `failed` — скопируй весь вывод и передай его агенту `debugger`
(как — в пункте 13).

## Часть 2. Живой бот

### 3. Запусти бота

```powershell
python -m app
```

**Должно получиться:** строка `Бот запущен: @твой_бот`, курсор мигает.
Это окно не закрывай до конца проверки.

### 4. Напиши боту `/start`

**Должно получиться:** приветствие, в котором **упомянуты команды `/today` и `/tomorrow`**.
Текст обычный, без значков `<b>` и `&amp;`.

### 5. Напиши `/help`

**Должно получиться:** в списке команд есть строки:

```
/today — пары на сегодня
/tomorrow — пары на завтра
```

### 6. Напиши `/today`

**Должно получиться:** сообщение из двух частей.

Первая строка — **жирная**: день недели и дата, например `Сегодня, четверг, 3 сентября`.
Вторая строка — `Неделя — числитель` или `Неделя — знаменатель`.

Проверь по порядку:

1. День недели и дата совпадают с календарём на телефоне.
2. Слово «числитель»/«знаменатель» совпадает с таблицей недель из шпаргалки выше.
3. Список пар совпадает с нужной строкой второй шпаргалки: столько же пар, то же время,
   те же предметы и аудитории.
4. Время написано жирным, а тегов `<b>` в тексте **не видно** — если видно теги,
   это ошибка, зови `debugger`.

### 7. Напиши `/tomorrow`

**Должно получиться:** то же самое, но заголовок начинается со слова `Завтра`
и дата на день больше. Если завтра понедельник — не забудь, что вместе с ним
меняется и чётность недели (см. таблицу).

### 8. Проверь пустой день

Самый важный пункт этапа: бот обязан спокойно сказать «пар нет», а не молчать
и не показывать чужие пары.

Пустые дни: **четверг по числителю**, **пятница и суббота по знаменателю**,
и любое **воскресенье**.

Как проверить, не дожидаясь нужного дня:

- если сегодня один из этих дней — напиши `/today`;
- если завтра один из этих дней — напиши `/tomorrow`;
- если ни то, ни другое — воспользуйся пунктом 11 (посмотреть любой день).

**Должно получиться:** сообщение вида

```
Сегодня, четверг, 3 сентября
Неделя — числитель

Сегодня пар нет — можно выдохнуть.
```

(для `/tomorrow` — «Завтра пар нет — можно выдохнуть»)

### 9. Проверь понедельник

В понедельник все пары дистанционные — это не ошибка расписания, а особенность группы.
Напиши `/today` в понедельник или `/tomorrow` в воскресенье.

**Должно получиться:** пары показаны (их три), и **у каждой** вместо адреса написано
`дистанционно`. Никаких «Вознесенский» и «Садовая» в этот день быть не должно.
Утренний будильник в такой день бот присылать не будет — это уже этап 5.

### 10. Проверь, что корпус зависит от чётности

Это то место, где легче всего проехать не туда.

Во **вторник по числителю** первая пара дня — на **Вознесенском, 46** (БЖД, В 570).
Во **вторник по знаменателю** первая пара дня — на **Садовой, 54** (Администрирование, С 407).

Проверь оба вторника (в живом чате это две разные недели, поэтому проще посмотреть
через пункт 11: даты `2026-09-01` — числитель и `2026-09-08` — знаменатель).

**Должно получиться:** адреса в первой паре разные, ровно как написано выше.

### 11. (по желанию) Посмотреть любой день, не дожидаясь его

Открой **второе** окно PowerShell, перейди в папку проекта, включи окружение (пункт 1)
и выполни одну строку — в ней три числа: год, месяц, день.

```powershell
python -c "from datetime import date; from app.schedule import lessons_on, format_day; d = date(2026, 9, 9); print(format_day(d, lessons_on(d), today=d))"
```

Чтобы посмотреть другой день, поменяй `2026, 9, 9` на нужную дату (например
`2026, 9, 1` — вторник по числителю).

**Должно получиться:** тот же текст, что бот прислал бы в Telegram. Разница только
в том, что здесь видны служебные значки `<b>` и `</b>` — в Telegram на их месте
жирный шрифт. Это нормально.

Пример для 9 сентября 2026 (среда, знаменатель) — ровно 4 пары:

```
<b>Сегодня, среда, 9 сентября</b>
Неделя — знаменатель

<b>10:05–11:30</b> — Прикладной дизайн (Пр)
пр. Вознесенский, д. 46, ауд. В 484 · Савенкова П.В.
...
```

### 12. Останови бота

Вернись в окно с ботом и нажми **Ctrl+C**.

**Должно получиться:** строки `Получен Ctrl+C, выключаемся` и `Бот остановлен`,
без красного текста и слова `Traceback`.

## Часть 3. Если что-то пошло не так

### 13. Как передать проблему

Скопируй текст ошибки или сделай скриншот ответа бота, открой Claude Code в папке
проекта командой `claude` и напиши:

```
Используй агента debugger. Этап 2, пункт N чек-листа. Ожидал: <что должно быть>.
Получил: <что пришло на самом деле>.
```

Частые случаи:

| Что видно | Что это значит |
|---|---|
| на `/today` бот отвечает «Я пока не знаю такой команды» | команда не подключена — зови `debugger` |
| в сообщении видны теги `<b>`, `&amp;` | сломалась разметка HTML — зови `debugger` |
| «Не получилось прочитать расписание…» | испорчен файл `data/schedule_4md4.json`, восстанови его из git и перезапусти бота |
| чётность недели не совпала с таблицей | самое серьёзное: зови `debugger` и укажи дату и что ответил бот |
| пар показано больше или меньше, чем в шпаргалке | зови `debugger`, приложи скриншот |
| время в заголовке «съехало» на день (бот пишет завтрашнюю дату) | часовой пояс на компьютере/сервере; укажи это в сообщении |
