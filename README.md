# Бот-будильник для группы 4-МД-4

Считает, во сколько тебя разбудить, чтобы успеть к первой очной паре — с учётом того,
в каком из трёх корпусов эта пара, какая сейчас неделя (числитель или знаменатель) и
сколько сейчас пробок по твоему маршруту. Плюс заметки по конкретным занятиям
и напоминания о дедлайнах за сутки.

**Начни отсюда:** `docs/SETUP_WINDOWS.md`

- `CLAUDE.md` — техзадание и правила проекта для Claude Code
- `docs/PLAN.md` — семь этапов разработки
- `.claude/agents/` — четыре агента: pm, dev, debugger, tester
- `data/schedule_4md4.json` — расписание группы, уже разобранное из Excel
- `scripts/parse_schedule.py` — пересобрать JSON, если деканат выпустит новый файл
